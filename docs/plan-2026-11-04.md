# Importin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust binary `importin` that serves six read-only MCP tools over stdio against Apple Mail's local store, with recipients from the Envelope Index and S/MIME decryption through the login keychain.

**Architecture:** One crate. `envelope` answers every metadata question from the live Envelope Index opened read-only; `paths`+`emlx`+`mime` read one message file on demand; `smime` peels enveloped messages through a `Decryptor` subprocess; `read` composes them into tool responses; `tools` is rmcp glue; `doctor` is the CLI health check. No index, no watcher, no AppleScript, nothing written to disk.

**Tech Stack:** Rust stable (rustup), rmcp 3.x (server, macros, stdio), rusqlite (bundled), mail-parser 1.x, plist, serde/serde_json/toml, chrono, glob, base64, zip + quick-xml, calamine, pdf-extract, thiserror, tempfile (dev). Subprocesses: `/usr/bin/security`, `openssl`.

**Spec:** `DESIGN.md` (same repo). Store facts: `DESIGN.md` §4–§5; tool shapes: §8; doctor: §9; config: §10; tests: §11.

## Global Constraints

- Read-only by construction: SQLite opened `SQLITE_OPEN_READ_ONLY | SQLITE_OPEN_URI | SQLITE_OPEN_NO_MUTEX`; never `immutable=1`; no `osascript`, no network, nothing written outside `$TMPDIR` (snapshot fallback only).
- Never read the user's real mail in any test or step. `IMPORTIN_MAIL_ROOT` always points at a fixture in tests. Real-store steps print anonymised numbers only.
- Logs to stderr only (stdout is the MCP channel). `IMPORTIN_LOG` level, default `warn`.
- Budgets (release, fixture or 100k store): first MCP reply < 50 ms; header `search` < 50 ms; `get_email` < 30 ms plain, < 300 ms encrypted; body scan ≤ 2 s at `body_scan_max`.
- `max_chars` default 20 000; `limit` 1–200 default 25; `body_scan_days` 90; `body_scan_max` 500; decrypt timeout 10 s.
- Dates serialised ISO 8601 with offset (`chrono::DateTime<FixedOffset>::to_rfc3339`). Address JSON `{name, address}`.
- Unknown config keys are a startup error. No `--read-only` flag exists anywhere.
- Apache-2.0; no code copied from mailgrep (MIT, knowledge only) or apple-mail-mcp (GPL).
- Commit after every task with a one-line conventional message; no `Co-Authored-By` trailers, never `-c user.*`.
- Toolchain: `export PATH="/opt/homebrew/opt/rustup/bin:$HOME/.cargo/bin:$PATH"` before cargo.

## Review Focus

1. Mailbox URL path with spaces, umlauts or `%20` (e.g. `Gesendete%20Objekte`) must map to the `<name>.mbox` directory after percent-decoding; test in Task 4.
2. `addresses.comment` NULL or empty, and `addresses.address` NULL, must yield `{name: "", address: ""}` not an error; test in Task 3.
3. Search terms containing `%`, `_` or `'` must be escaped for LIKE (an underscore must not act as a wildcard); test in Task 3.
4. A body in ISO-8859-1 with umlauts (`Content-Transfer-Encoding: quoted-printable`) must decode to the right UTF-8 text; test in Task 5.
5. An `.emlx` larger than 64 MiB is refused with a clear error instead of being read into memory; test in Task 4.
